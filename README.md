# Internspark Machine Learning Internship Projects

## Overview

This repository contains the Machine Learning projects completed during my internship at Internspark. The internship provided hands-on experience in data preprocessing, exploratory data analysis, feature engineering, model building, evaluation, and deployment concepts using Python and Machine Learning libraries.

## Projects Included

### 1. Iris Flower Classification

A multiclass classification project that classifies iris flowers into three species based on sepal and petal measurements.

**Skills Used:**

* Exploratory Data Analysis
* Data Visualization
* Classification Models
* Accuracy Evaluation
* Machine Learning Fundamentals

### 2. House Price Prediction

A regression-based machine learning project that predicts house prices using various housing features. The project involves data cleaning, feature selection, model training, and performance evaluation.

**Skills Used:**

* Data Preprocessing
* Feature Engineering
* Regression Algorithms
* Model Evaluation
* Scikit-learn

### 3. Titanic Survival Prediction

A classification project that predicts whether a passenger survived the Titanic disaster based on passenger information such as age, gender, ticket class, and fare.

**Skills Used:**

* Data Cleaning
* Missing Value Handling
* Feature Encoding
* Classification Algorithms
* Performance Metrics
